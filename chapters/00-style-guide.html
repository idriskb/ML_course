Definitions, theorems and proofs

Definitions, lemmas, theorems, examples and exercises share a single counter within each chapter, so Theorem 0.3 always comes after Lemma 0.2. Proofs are collapsed by default: try the statement yourself first, then open the proof. Use Expand all proofs in the right-hand panel when revising.

Let $(\bx_1, y_1), \dots, (\bx_n, y_n)$ be a training sample and $\ell : \R \times \R \to [0, \infty)$ a loss function. The empirical risk of a predictor $h : \R^d \to \R$ is $$\hat R_n(h) = \frac{1}{n} \sum_{i=1}^{n} \ell\big(h(\bx_i), y_i\big).$$

For linear predictors $h_{\bw}(\bx) = \bw\T\bx$ and the squared loss $\ell(\hat y, y) = (\hat y - y)^2$, minimising the empirical risk amounts to minimising $$J(\bw) = \norm{\by - \bX\bw}^2.$$

For any $\bX \in \R^{n \times d}$ the matrix $\bX\T\bX$ is positive semidefinite. It is positive definite if and only if $\bX$ has full column rank $d$.

Proof

For every $\bv \in \R^d$ we have $\bv\T\bX\T\bX\bv = \norm{\bX\bv}^2 \geq 0$, so $\bX\T\bX$ is positive semidefinite. Equality holds if and only if $\bX\bv = \mathbf{0}$. Hence $\bv\T\bX\T\bX\bv > 0$ for every $\bv \neq \mathbf{0}$ exactly when the kernel of $\bX$ is trivial, that is, when $\bX$ has full column rank.

Assume $\bX \in \R^{n \times d}$ has full column rank. Then $J(\bw) = \norm{\by - \bX\bw}^2$ has a unique minimiser $$\hatw = (\bX\T\bX)^{-1}\bX\T\by.$$

Proof

The function $J$ is a quadratic with Hessian $\nabla^2 J(\bw) = 2\bX\T\bX$, which is positive definite by . Hence $J$ is strictly convex and has at most one minimiser. Since $J$ is differentiable and convex, $\bw$ minimises $J$ if and only if $\nabla J(\bw) = \mathbf{0}$. As derived in , this condition is equivalent to the normal equations $\bX\T\bX\bw = \bX\T\by$. Because $\bX\T\bX$ is invertible, they have the unique solution $\hatw = (\bX\T\bX)^{-1}\bX\T\by$.

If $\bX$ is rank deficient (for instance when $d > n$), the minimiser is not unique. A canonical choice is the minimum-norm solution $\hatw = \bX^{+}\by$, where $\bX^{+}$ is the Moore–Penrose pseudoinverse. We return to this in the chapter on regularisation.

Step-by-step derivations

Longer computations are revealed one step at a time. Try to predict the next line before you press Next step.

  1. Expand the squared norm.

    $$J(\bw) = (\by - \bX\bw)\T(\by - \bX\bw) = \by\T\by - 2\bw\T\bX\T\by + \bw\T\bX\T\bX\bw.$$

  2. Differentiate term by term, using $\nabla_{\bw}(\bw\T\mathbf{a}) = \mathbf{a}$ and $\nabla_{\bw}(\bw\T\mathbf{A}\bw) = (\mathbf{A} + \mathbf{A}\T)\bw$ with $\mathbf{A} = \bX\T\bX$ symmetric.

    $$\nabla J(\bw) = -2\bX\T\by + 2\bX\T\bX\bw.$$

  3. Set the gradient to zero.

    $$\bX\T\bX\bw = \bX\T\by.$$

  4. If $\bX\T\bX$ is invertible, multiply on the left by its inverse.

    $$\hatw = (\bX\T\bX)^{-1}\bX\T\by.$$

Interactive figures

Closed-form solutions are the exception. Most models are fitted iteratively, typically by gradient descent: starting from $x_0$, repeat $$x_{k+1} = x_k - \eta\, \nabla f(x_k), \tag{0.1}$$ where $\eta > 0$ is the learning rate. The figure below runs (0.1) on the non-convex function $f(x) = \tfrac14 x^4 - x^2 + 0.3x$, which has two local minima.

Intuition

The gradient points uphill, so each step moves downhill. The learning rate sets how far you trust this local, linear picture of $f$. Where $f$ curves sharply, a long step overshoots the valley.

The next result makes "not too large" precise. A differentiable function $f$ is $L$-smooth if $\norm{\nabla f(\bx) - \nabla f(\by)} \leq L \norm{\bx - \by}$ for all $\bx, \by$.

Let $f : \R^d \to \R$ be $L$-smooth and $0 \lt \eta \leq 1/L$. Then for every $\bx$, $$f\big(\bx - \eta \nabla f(\bx)\big) \leq f(\bx) - \frac{\eta}{2}\norm{\nabla f(\bx)}^2.$$

Proof

$L$-smoothness implies the quadratic upper bound $f(\by) \leq f(\bx) + \nabla f(\bx)\T(\by - \bx) + \tfrac{L}{2}\norm{\by - \bx}^2$. Take $\by = \bx - \eta\nabla f(\bx)$ and write $\mathbf{g} = \nabla f(\bx)$: $$f(\by) \leq f(\bx) - \eta\norm{\mathbf{g}}^2 + \frac{L\eta^2}{2}\norm{\mathbf{g}}^2 = f(\bx) - \eta\Big(1 - \frac{L\eta}{2}\Big)\norm{\mathbf{g}}^2.$$ Since $L\eta \leq 1$, we have $1 - L\eta/2 \geq 1/2$, which gives the claim.

For the function in , $f''(x) = 3x^2 - 2$, so on $[-2.5, 2.5]$ we have $|f''| \leq 16.75$. While the iterates stay in this interval, guarantees a decrease at every step for $\eta \leq 1/16.75 \approx 0.06$. Starting from $x_0 = 2.2$ with $\eta = 0.06$, the iterates descend smoothly into the local minimum near $x \approx 1.33$. With $\eta = 0.5$, the first step jumps over the barrier into the other basin, and the iterates end up bouncing between two points instead of settling at the minimum. Try both in the figure.

Common pitfall

A smaller loss after one step does not mean the method converges to the global minimum. On non-convex functions, the starting point decides which basin you end up in.

Code

Short snippets show how the mathematics turns into an implementation.

import numpy as np

def gradient_descent(grad, x0, lr=0.1, steps=100):
    """Iterate x_{k+1} = x_k - lr * grad(x_k)."""
    x = np.asarray(x0, dtype=float)
    for _ in range(steps):
        x = x - lr * grad(x)
    return x

# Least squares: grad J(w) = 2 X^T (X w - y)
X, y = np.random.randn(100, 3), np.random.randn(100)
w_hat = gradient_descent(lambda w: 2 * X.T @ (X @ w - y), np.zeros(3), lr=1e-3, steps=5000)

Exercises

Let $f(x) = \tfrac{a}{2}x^2$ with $a > 0$. Show that gradient descent (0.1) converges to $0$ from every starting point if and only if $0 \lt \eta \lt 2/a$. What happens for $\eta = 2/a$?

Solution

Here $f'(x) = ax$, so $x_{k+1} = (1 - \eta a)\,x_k$ and $x_k = (1 - \eta a)^k x_0$. This tends to $0$ for every $x_0$ if and only if $|1 - \eta a| \lt 1$, that is, $0 \lt \eta \lt 2/a$. For $\eta = 2/a$ we get $x_k = (-1)^k x_0$: the iterates oscillate forever between $x_0$ and $-x_0$.

Compute the Hessian of $J(\bw) = \norm{\by - \bX\bw}^2$ and use it to give a second proof that every solution of the normal equations minimises $J$, even when $\bX$ is rank deficient.

Solution

From the derivation, $\nabla^2 J(\bw) = 2\bX\T\bX$, which is positive semidefinite by . So $J$ is convex, and for a differentiable convex function every stationary point is a global minimiser. The stationary points are exactly the solutions of $\bX\T\bX\bw = \bX\T\by$.

Key takeaways

  • Least squares has the closed form $\hatw = (\bX\T\bX)^{-1}\bX\T\by$ when $\bX$ has full column rank.
  • Gradient descent decreases an $L$-smooth objective at every step if $\eta \leq 1/L$.
  • On non-convex problems, both the learning rate and the starting point matter.
