Neural networks

Kernel methods make a linear model non-linear by fixing a feature map in advance. A neural network learns the feature map instead. It stacks simple layers, each an affine map followed by a non-linear function, and has a fixed number of parameters however large the data set. This chapter defines these networks, explains why the non-linearity is essential, compares the usual activation functions, and proves that one hidden layer is already enough to approximate any continuous function. How to train a network is the subject of the next chapter.

Why neural networks?

Supervised learning looks for a function $f : \R^p \to \mathcal Y$ with $f(\bx_i) \approx y_i$ on the training data that also works on new inputs. So far we have searched for $f$ in four kinds of model families.

The limits of linear models

Linear regression uses $f(\bx) = \bw\T\bx + b$; logistic regression passes the same quantity through a fixed sigmoid. Both are simple, have convex objectives, and have interpretable coefficients. Their limitation is linearity:

  • the decision boundary of logistic regression is a hyperplane;
  • along any line $\bx + t\bu$ in input space, the prediction $\bw\T\bx + b$ changes at a constant rate;
  • more data does not help if the true relationship is strongly non-linear: the bias stays.

Three non-linear approaches, and their limits

  • k-nearest neighbours (Chapter 7) predicts from the closest training points. It has no fixed functional form and its boundaries can be arbitrarily complex. But the whole training set must be stored and searched at prediction time, it suffers from the curse of dimensionality, and it depends on $k$, the distance and the scaling of the features.
  • Trees and ensembles (Chapter 8) split the input space into boxes. They capture interactions and need little preprocessing. But a single tree has high variance, axis-aligned splits make smooth or diagonal boundaries expensive, and the fitted function is piecewise constant, hence not differentiable.
  • Kernel methods (Chapter 9) fit a linear model on features $\phi(\bx)$ through the kernel $k(\bx, \bx') = \phi(\bx)\T\phi(\bx')$. They are flexible and convex. But there is one coefficient $\alpha_i$ per training point, so memory grows like $N^2$ and time like $N^3$; and once the kernel is chosen, so are the features.

A tree grown until its leaves are small has a number of leaves that grows with $N$, which is why it counts as non-parametric. On tabular data, boosted trees remain very strong competitors to neural networks.

Learning the features

Neural networks keep the good part of kernel methods: a linear model on top of non-linear features, $$f(\bx) = \bw\T\bh(\bx) + b .$$ The difference is that the feature map $\bh$ is not fixed in advance. It is itself a parametrised function, built by composing simple layers, and its parameters are fitted to the data together with $\bw$ and $b$. This is what makes networks so effective on raw, high-dimensional inputs such as pixels, audio waveforms or text, where good hand-made features are hard to design: the network learns the features from the data.

The neuron

A neuron (or unit) with input $\bx \in \R^p$ computes $$z = \bw\T\bx + b, \qquad a = \sigma(z),$$ where $\bw \in \R^p$ are its weights, $b \in \R$ its bias, $\sigma : \R \to \R$ a fixed activation function, $z$ the pre-activation and $a$ the neuron's output, its activation.

Logistic regression (Chapter 4) is exactly one neuron with the sigmoid activation $\sigma(z) = 1/(1 + e^{-z})$: its output $a = \sigma(\bw\T\bx + b)$ is read as $\P(y = 1 \mid \bx)$. Linear regression is one neuron with the identity activation $\sigma(z) = z$.

One neuron is a linear model. A network connects many neurons in layers, and that is where the non-linearity comes from.

Feedforward networks

A layer is a group of neurons that all read the same input vector. Stacking the weight vectors of its $n$ neurons as the rows of a matrix $\bW$, the layer maps a vector to a vector: $$\mathbf z = \bW\ba + \bb, \qquad \ba' = \sigma(\mathbf z),$$ where $\sigma$ is applied to each entry.

A feedforward neural network (or multilayer perceptron) with $L$ layers of widths $n_1, \dots, n_L$ and input dimension $n_0 = p$ computes, for $\ell = 1, \dots, L$, $$\mathbf z^{(\ell)} = \bW^{(\ell)}\ba^{(\ell-1)} + \bb^{(\ell)}, \qquad \ba^{(\ell)} = \sigma^{(\ell)}\big(\mathbf z^{(\ell)}\big), \qquad \ba^{(0)} = \bx,$$ with weight matrices $\bW^{(\ell)} \in \R^{n_\ell \times n_{\ell-1}}$, bias vectors $\bb^{(\ell)} \in \R^{n_\ell}$ and activation functions $\sigma^{(\ell)}$ applied entrywise. Its output is $f_\theta(\bx) = \ba^{(L)}$, and its parameters are $\theta = \{\bW^{(\ell)}, \bb^{(\ell)} : \ell = 1, \dots, L\}$.

  • The input layer is $\ba^{(0)} = \bx$ (it has no parameters).
  • Layers $1, \dots, L - 1$ are hidden layers: their values are not observed in the data. A network with $L - 1 \geq 2$ hidden layers is called deep.
  • Layer $L$ is the output layer; its activation $\sigma^{(L)}$ is chosen for the task ().

The architecture (number of layers, widths, activations) fixes a family of functions; the parameters $\theta$ pick one function in that family. The information flows in one direction, from input to output, hence "feedforward".

The forward pass

Evaluating $f_\theta(\bx)$ layer by layer is called the forward pass. It is a sequence of matrix–vector products and entrywise functions.

A network with $p = 2$ inputs, one hidden layer of two ReLU units ($\operatorname{ReLU}(z) = \max(0, z)$) and one output: $$\bW^{(1)} = \begin{pmatrix} 1 & -1 \\ 1 & 1 \end{pmatrix}, \quad \bb^{(1)} = \begin{pmatrix} 0 \\ -1 \end{pmatrix}, \quad \bW^{(2)} = \begin{pmatrix} 2 & -1 \end{pmatrix}, \quad b^{(2)} = 0.5 .$$ Evaluate it at $\bx = (1, 2)$.

Step 1: hidden pre-activations. $$\mathbf z^{(1)} = \bW^{(1)}\bx + \bb^{(1)} = \begin{pmatrix} 1 - 2 + 0 \\ 1 + 2 - 1 \end{pmatrix} = \begin{pmatrix} -1 \\ 2 \end{pmatrix} .$$

Step 2: hidden activations. ReLU sets the negative entry to zero: $$\ba^{(1)} = \operatorname{ReLU}\big(\mathbf z^{(1)}\big) = \begin{pmatrix} 0 \\ 2 \end{pmatrix} .$$ The first unit is inactive at this input.

Step 3: output. $$z^{(2)} = \bW^{(2)}\ba^{(1)} + b^{(2)} = 2 \cdot 0 - 1 \cdot 2 + 0.5 = -1.5 .$$ For regression (identity output) the prediction is $\hat y = -1.5$.

Step 4: as a classifier. With a sigmoid output instead, the network predicts $\P(y = 1 \mid \bx) = \sigma(-1.5) = 1/(1 + e^{1.5}) \approx 0.18$, so class $0$.

For $N$ inputs at once, put them as the rows of $\bX \in \R^{N \times p}$; then each layer is one matrix product, $\mathbf Z^{(\ell)} = \mathbf A^{(\ell-1)}\bW^{(\ell)\top} + \mathbf 1\bb^{(\ell)\top}$, which is how software evaluates networks efficiently.

Counting parameters

A feedforward network with widths $n_0 = p, n_1, \dots, n_L$ has $$\#\theta = \sum_{\ell=1}^L n_\ell\,(n_{\ell-1} + 1)$$ parameters. The count depends on the architecture only, not on the number $N$ of training points.

Proof

Step 1: one layer. $\bW^{(\ell)} \in \R^{n_\ell \times n_{\ell-1}}$ has $n_\ell n_{\ell-1}$ entries and $\bb^{(\ell)} \in \R^{n_\ell}$ has $n_\ell$, so layer $\ell$ has $$n_\ell n_{\ell-1} + n_\ell = n_\ell\,(n_{\ell-1} + 1)$$ parameters: each of its $n_\ell$ neurons has $n_{\ell-1}$ weights and one bias.

Step 2: add the layers. The layers have disjoint parameters; summing over $\ell = 1, \dots, L$ gives the formula.

For handwritten digits of $28 \times 28 = 784$ pixels, a network with one hidden layer of 128 units and 10 outputs has $128 \cdot 785 + 10 \cdot 129 = 101\,770$ parameters, whether it is trained on a thousand images or on sixty thousand. A kernel method trained on sixty thousand images would need a kernel matrix with $3.6 \times 10^9$ entries.

Hidden layers as learned features

Write $\bh_\theta(\bx) = \ba^{(L-1)}$ for the last hidden layer. Then $$f_\theta(\bx) = \sigma^{(L)}\big(\bW^{(L)}\bh_\theta(\bx) + \bb^{(L)}\big):$$ the output layer is an ordinary linear model (identity output) or logistic regression (sigmoid output) applied to the features $\bh_\theta(\bx)$. Why the activations must be non-linear

If every activation were the identity, depth would buy nothing.

If $\sigma^{(\ell)}(z) = z$ for every layer, the network is an affine map: $$f_\theta(\bx) = \tilde\bW\bx + \tilde\bb, \qquad \tilde\bW = \bW^{(L)}\bW^{(L-1)}\cdots\bW^{(1)}, \qquad \tilde\bb = \sum_{k=1}^L \bW^{(L)}\cdots\bW^{(k+1)}\bb^{(k)},$$ where the empty product (for $k = L$) is the identity.

Proof

We prove by induction on $\ell$ that $$\ba^{(\ell)} = \bW^{(\ell)}\cdots\bW^{(1)}\bx + \sum_{k=1}^{\ell} \bW^{(\ell)}\cdots\bW^{(k+1)}\bb^{(k)} . \tag{1}$$

Step 1: first layer. With the identity activation, $\ba^{(1)} = \mathbf z^{(1)} = \bW^{(1)}\bx + \bb^{(1)}$, which is (1) for $\ell = 1$.

Step 2: from $\ell$ to $\ell + 1$. Assume (1) for $\ell$. Then $$\begin{aligned} \ba^{(\ell+1)} &= \bW^{(\ell+1)}\ba^{(\ell)} + \bb^{(\ell+1)} \\ &= \bW^{(\ell+1)}\bW^{(\ell)}\cdots\bW^{(1)}\bx + \sum_{k=1}^{\ell} \bW^{(\ell+1)}\bW^{(\ell)}\cdots\bW^{(k+1)}\bb^{(k)} + \underbrace{\bb^{(\ell+1)}}_{k\,=\,\ell+1\ \text{term}} , \end{aligned}$$ which is (1) for $\ell + 1$.

Step 3: conclude. Take $\ell = L$ in (1).

A network whose hidden layers all use the identity activation and whose output is a sigmoid computes $\sigma(\tilde\bw\T\bx + \tilde b)$: it is logistic regression, and its decision boundary is a hyperplane, whatever the depth and the widths.

Depth without non-linearity even loses something: $\operatorname{rank}\tilde\bW \leq \min_\ell n_\ell$, so a narrow hidden layer restricts which linear maps can be represented. (A linear network with a narrow middle layer will reappear in the chapter on autoencoders, where it turns out to be PCA.)

Activation functions

The choice of $\sigma$ in the hidden layers affects what the network can represent and, just as much, how easily it can be trained by gradient descent: gradients flow backwards through the derivatives $\sigma'$.

Sigmoid and tanh

The sigmoid and the hyperbolic tangent are $$\sigma(z) = \frac{1}{1 + e^{-z}} \in (0, 1), \qquad \tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} \in (-1, 1) .$$

(a) $\sigma'(z) = \sigma(z)\big(1 - \sigma(z)\big)$, so $0 < \sigma'(z) \leq \frac14$, with equality only at $z = 0$.
(b) $\tanh(z) = 2\sigma(2z) - 1$, and $\tanh'(z) = 1 - \tanh^2(z) \in (0, 1]$.
(c) Both derivatives tend to $0$ as $|z| \to \infty$.

Proof

Step 1: derivative of the sigmoid. $$\sigma'(z) = \frac{e^{-z}}{(1 + e^{-z})^2} = \underbrace{\frac{1}{1 + e^{-z}}}_{=\ \sigma(z)}\cdot \underbrace{\frac{e^{-z}}{1 + e^{-z}}}_{=\ 1 - \sigma(z)} .$$

Step 2: its maximum. With $s = \sigma(z) \in (0, 1)$, $$s(1 - s) = \tfrac14 - \big(s - \tfrac12\big)^2 \leq \tfrac14 ,$$ with equality only if $s = \frac12$, i.e. $z = 0$.

Step 3: tanh in terms of the sigmoid. Multiply numerator and denominator by $e^{-z}$: $$\tanh(z) = \frac{1 - e^{-2z}}{1 + e^{-2z}} = \frac{2 - (1 + e^{-2z})}{1 + e^{-2z}} = \frac{2}{1 + e^{-2z}} - 1 = 2\sigma(2z) - 1 .$$

Step 4: derivative of tanh. By the chain rule and Step 1, $$\tanh'(z) = 4\sigma'(2z) = 4\sigma(2z)\big(1 - \sigma(2z)\big) .$$ Since $\sigma(2z) = \frac{1 + \tanh z}{2}$ and $1 - \sigma(2z) = \frac{1 - \tanh z}{2}$, this is $(1 + \tanh z)(1 - \tanh z) = 1 - \tanh^2(z)$, which lies in $(0, 1]$.

Step 5: the tails. As $|z| \to \infty$, $\sigma(z) \to 0$ or $1$ and $\tanh(z) \to \pm1$, so both derivatives tend to $0$.

Both functions are smooth and S-shaped, and they saturate: for large $|z|$ the output barely changes and the derivative is nearly zero. Tanh is a rescaled sigmoid, but it is centred at zero (its outputs have both signs), which usually makes optimisation easier than with sigmoid hidden units, whose outputs are always positive.

Vanishing gradients

Training adjusts each parameter in proportion to how much the output changes when that parameter changes. In a deep network these sensitivities are products of many factors $\sigma'$. The simplest case already shows the problem.

Consider a chain of $L$ single neurons, $a_0 = x$ and $$a_\ell = \sigma(z_\ell), \qquad z_\ell = w_\ell a_{\ell-1} + b_\ell, \qquad \ell = 1, \dots, L .$$ Then $$\frac{d a_L}{dx} = \prod_{\ell=1}^L \sigma'(z_\ell)\,w_\ell ,$$ and with the sigmoid activation $$\Big|\frac{d a_L}{dx}\Big| \leq \frac{|w_1 w_2 \cdots w_L|}{4^L} .$$

Proof

Step 1: one layer. By the chain rule, $$\frac{d a_\ell}{d a_{\ell-1}} = \sigma'(z_\ell)\,\frac{d z_\ell}{d a_{\ell-1}} = \sigma'(z_\ell)\,w_\ell .$$

Step 2: compose. $a_L$ is a function of $a_{L-1}$, which is a function of $a_{L-2}$, and so on down to $a_0 = x$. The chain rule multiplies the factors of Step 1: $$\frac{d a_L}{dx} = \frac{d a_L}{d a_{L-1}}\cdot\frac{d a_{L-1}}{d a_{L-2}}\cdots\frac{d a_1}{d a_0} = \prod_{\ell=1}^L \sigma'(z_\ell)\,w_\ell .$$

Step 3: bound. By , $0 < \sigma'(z_\ell) \leq \frac14$ for every $\ell$, so the absolute value of the product is at most $\prod_\ell |w_\ell| / 4^L$.

With weights of size at most one and ten sigmoid layers, the derivative is below $4^{-10} \approx 10^{-6}$, and it is far smaller still if some units are saturated. The early layers then receive almost no signal and learn very slowly: the vanishing gradient problem. Tanh helps ($\tanh' \leq 1$) but still saturates. The same products appear in networks of any width; the general computation, backpropagation, is in the next chapter.

ReLU and its variants

The rectified linear unit and the leaky ReLU with slope $0 < \alpha < 1$ are $$\operatorname{ReLU}(z) = \max(0, z), \qquad \operatorname{LReLU}_\alpha(z) = \begin{cases} z, & z \geq 0, \\ \alpha z, & z < 0. \end{cases}$$ Their derivatives (for $z \neq 0$) are $\mathbf 1\{z > 0\}$ and $1$ or $\alpha$.

  • No saturation for $z > 0$. The derivative is exactly $1$ there, so in the chain of the product of the $\sigma'$ factors is $1$ along active units: no systematic shrinking. This is the main reason ReLU networks train faster and deeper.
  • Cheap and sparse. Evaluating it is a comparison; for a given input many units output exactly zero, as in .
  • Dying units. If a unit's pre-activation is negative for every training input (for instance after a large update made its bias very negative), it outputs $0$ everywhere and its derivative is $0$ everywhere. Gradient descent then never changes its weights: the unit is dead.
  • Leaky ReLU keeps a small slope $\alpha$ (e.g. $0.01$) for $z < 0$, so a unit always receives some gradient and can recover.

ReLU is not differentiable at $0$; in practice software uses $0$ (or $1$) for the derivative there, which does no harm. ReLU is the default choice for hidden layers today.

The output layer

The hidden layers can be the same for every task. What changes is the output activation, chosen so that the output has the right range, and the loss used to train it.

$K$ classes$K$softmax$(\P(y = k \mid \bx))_{k=1}^K$cross-entropy

The softmax of $\mathbf z \in \R^K$ is the vector with entries $$\operatorname{softmax}(\mathbf z)_k = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}}, \qquad k = 1, \dots, K .$$ The inputs $z_k$ are called logits.

(a) The entries of $\operatorname{softmax}(\mathbf z)$ are positive and sum to $1$.
(b) Adding a constant to every logit does not change the result: $\operatorname{softmax}(\mathbf z + c\mathbf 1) = \operatorname{softmax}(\mathbf z)$ for all $c \in \R$.
(c) For $K = 2$, $\operatorname{softmax}(\mathbf z)_1 = \sigma(z_1 - z_2)$: two-class softmax is the sigmoid of the difference of the logits.

Proof

Step 1: a probability vector. Each $e^{z_k} > 0$, so each entry is positive, and $$\sum_{k=1}^K \frac{e^{z_k}}{\sum_j e^{z_j}} = \frac{\sum_k e^{z_k}}{\sum_j e^{z_j}} = 1 .$$

Step 2: shift invariance. The factor $e^c$ cancels: $$\frac{e^{z_k + c}}{\sum_j e^{z_j + c}} = \frac{\cancel{e^{c}}\,e^{z_k}}{\cancel{e^{c}}\sum_j e^{z_j}} .$$

Step 3: two classes. Divide numerator and denominator by $e^{z_1}$: $$\frac{e^{z_1}}{e^{z_1} + e^{z_2}} = \frac{1}{1 + e^{-(z_1 - z_2)}} = \sigma(z_1 - z_2) .$$

Part (b) is used in every implementation: computing $e^{z_k}$ directly overflows for logits around $1000$, so one computes $\operatorname{softmax}(\mathbf z - \max_j z_j)$ instead, whose exponents are all $\leq 0$. Part (c) shows that the softmax output layer is the multi-class version of the sigmoid output, as in Chapter 4.

Universal approximation

How rich is the family of networks? Already with one hidden layer, it can approximate any continuous function as closely as we like. A one-hidden-layer network with one input, $m$ hidden units and identity output computes $$f_\theta(x) = c + \sum_{j=1}^m v_j\,\sigma(w_j x + b_j) .$$ We prove the result for ReLU, where the construction is explicit.

Building blocks: hinges, ramps and rectangles

One ReLU unit $v\operatorname{ReLU}(x - t)$ is a hinge: zero up to $t$, then a straight line of slope $v$. Two hinges make a ramp, and two ramps make a rectangle.

For $a < b$, the function $$r_{a,b}(x) = \frac{\operatorname{ReLU}(x - a) - \operatorname{ReLU}(x - b)}{b - a}$$ equals $0$ for $x \leq a$, $\frac{x - a}{b - a}$ for $a \leq x \leq b$, and $1$ for $x \geq b$.

Proof

Step 1: $x \leq a$. Then $x - a \leq 0$ and $x - b < 0$, so both ReLUs are $0$.

Step 2: $a \leq x \leq b$. Only the first ReLU is on: $r_{a,b}(x) = \frac{(x - a) - 0}{b - a}$.

Step 3: $x \geq b$. Both are on, and the $x$ cancels: $$r_{a,b}(x) = \frac{(\cancel{x} - a) - (\cancel{x} - b)}{b - a} = \frac{b - a}{b - a} = 1 .$$

As $b \to a$ the ramp becomes a step at $a$, and $r_{a,b} - r_{c,d}$ (with $b \leq c$) is a rectangle. A sum of narrow rectangles with heights $f(\text{midpoint})$ is a Riemann-sum picture of $f$; this is the usual intuition for universal approximation. With sigmoid units the same picture works: $\sigma(k(x - t))$ tends to the step $\mathbf 1\{x > t\}$ as $k \to \infty$ (for $x \neq t$), so two steep sigmoids make a rectangle. For ReLU there is a sharper construction: instead of rectangles, use the hinges directly to build broken lines.

Let $a = t_0 < t_1 < \dots < t_m = b$, and let $g : [a, b] \to \R$ be continuous and affine on each $[t_{j-1}, t_j]$, with slope $s_j$. Then for all $x \in [a, b]$, $$g(x) = g(a) + \sum_{j=1}^m v_j\,\operatorname{ReLU}(x - t_{j-1}), \qquad v_1 = s_1, \quad v_j = s_j - s_{j-1}\ (j \geq 2) .$$ So every continuous piecewise linear function on $[a, b]$ with $m$ pieces is a one-hidden-layer ReLU network with $m$ hidden units.

Proof

Call the right-hand side $h(x)$.

Step 1: same value at $a$. At $x = a = t_0$, every $x - t_{j-1} \leq 0$, so every ReLU is $0$ and $h(a) = g(a)$.

Step 2: $h$ is affine on each piece. On $(t_{k-1}, t_k)$, the unit $j$ is on ($x > t_{j-1}$) exactly when $j \leq k$, and then it equals $x - t_{j-1}$. So $$h(x) = g(a) + \sum_{j=1}^{k} v_j\,(x - t_{j-1}) \quad\text{on } (t_{k-1}, t_k),$$ an affine function of $x$.

Step 3: the slopes telescope. The slope of $h$ on $(t_{k-1}, t_k)$ is $$\sum_{j=1}^{k} v_j = s_1 + (s_2 - s_1) + (s_3 - s_2) + \dots + (s_k - s_{k-1}) = s_k ,$$ the slope of $g$ on the same piece.

Step 4: conclude. $g$ and $h$ are continuous, agree at $a$ and have the same slope on each piece, so $g - h$ is continuous, zero at $a$ and constant on each piece. Hence $g - h = 0$ on $[t_0, t_1]$, then on $[t_1, t_2]$, and so on up to $b$.

The universal approximation theorem

Let $f : [a, b] \to \R$ be continuous and $\varepsilon > 0$. There is a one-hidden-layer ReLU network $f_\theta(x) = c + \sum_{j=1}^m v_j\operatorname{ReLU}(w_j x + b_j)$ such that $$\sup_{x \in [a, b]}\,\big|f(x) - f_\theta(x)\big| < \varepsilon .$$

Proof

Step 1: uniform continuity. A continuous function on a closed bounded interval is uniformly continuous: there is $\delta > 0$ such that $$|x - x'| \leq \delta \implies |f(x) - f(x')| < \frac\varepsilon2 .$$

Step 2: a grid. Choose $m$ with $(b - a)/m \leq \delta$ and let $t_j = a + j(b - a)/m$, $j = 0, \dots, m$. Let $g$ be the broken line through the points $(t_j, f(t_j))$: affine on each $[t_{j-1}, t_j]$ and equal to $f$ at the grid points.

Step 3: the broken line is close to $f$. Take $x \in [t_{j-1}, t_j]$ and write $x = \lambda t_{j-1} + (1 - \lambda)t_j$ with $\lambda \in [0, 1]$. Then $g(x) = \lambda f(t_{j-1}) + (1 - \lambda)f(t_j)$, and $$f(x) - g(x) = \lambda\big(f(x) - f(t_{j-1})\big) + (1 - \lambda)\big(f(x) - f(t_j)\big) .$$ Both $|x - t_{j-1}|$ and $|x - t_j|$ are at most $\delta$, so by Step 1 $$|f(x) - g(x)| < \lambda\frac\varepsilon2 + (1 - \lambda)\frac\varepsilon2 = \frac\varepsilon2 < \varepsilon .$$

Step 4: the broken line is a network. By , $$g(x) = f(a) + \sum_{j=1}^m v_j\operatorname{ReLU}(x - t_{j-1}) \quad\text{on } [a, b],$$ a network with $m$ hidden units, weights $w_j = 1$, biases $b_j = -t_{j-1}$ and $c = f(a)$.

The same holds in any dimension and for essentially any activation. We state it without proof.

Let $\sigma : \R \to \R$ be continuous and not a polynomial, and let $K \subset \R^p$ be closed and bounded. For every continuous $f : K \to \R$ and every $\varepsilon > 0$ there exist $m$ and parameters $\bw_j \in \R^p$, $b_j, v_j, c \in \R$ such that $$\sup_{\bx \in K}\,\Big|f(\bx) - c - \sum_{j=1}^m v_j\,\sigma\big(\bw_j\T\bx + b_j\big)\Big| < \varepsilon .$$

The theorem covers sigmoid, tanh, ReLU and leaky ReLU. The condition "not a polynomial" cannot be dropped.

If $\sigma$ is a polynomial of degree $d$, every one-hidden-layer network $f_\theta$ on $[0, 1]$ is a polynomial of degree at most $d$, and there is $\varepsilon > 0$ such that no such network approximates $x^{d+1}$ within $\varepsilon$, however many hidden units it has.

Proof

Step 1: each unit is a polynomial. If $\sigma(z) = \sum_{k=0}^d \beta_k z^k$, then $\sigma(wx + b) = \sum_{k=0}^d \beta_k (wx + b)^k$ is a polynomial in $x$ of degree at most $d$.

Step 2: so is the network. A linear combination of such units plus a constant stays in the space $\mathcal P_d$ of polynomials of degree at most $d$, whatever $m$ is.

Step 3: $x^{d+1}$ is at positive distance from $\mathcal P_d$. $\mathcal P_d$ is a finite-dimensional subspace of the continuous functions on $[0, 1]$ with the norm $\norm{u}_\infty = \sup_x|u(x)|$. Finite-dimensional subspaces are closed (a standard fact of analysis), and $x^{d+1} \notin \mathcal P_d$. So $$\varepsilon = \inf_{q \in \mathcal P_d}\ \sup_{x \in [0, 1]}\big|x^{d+1} - q(x)\big| > 0 ,$$ and no network is closer than $\varepsilon$ to $x^{d+1}$.

What the theorem does not say

  • It is an existence result. It says suitable parameters exist, not how to find them. Finding them from data is the job of gradient descent and backpropagation (next chapter), which may stop at a worse local solution.
  • It says nothing about generalisation. A network that can approximate anything can also fit the noise in the training data. Controlling this (regularisation, early stopping, validation) is as important as for any flexible model.
  • The number of units may be huge. In the proof, the grid spacing must be small enough for the function to vary by less than $\varepsilon/2$. With $p$ inputs a grid with spacing $\delta$ has about $(1/\delta)^p$ cells: the curse of dimensionality of Chapter 7 again. The theorem does not say that one wide layer is a good architecture.

Why depth?

Deep networks are used in practice because composing layers can be far more economical than widening one layer. The following example makes this precise in one dimension.

A one-hidden-layer ReLU network with one input and $m$ hidden units is continuous and piecewise linear with at most $m + 1$ linear pieces.

Proof

Step 1: each unit has at most one kink. If $w_j \neq 0$, the unit $v_j\operatorname{ReLU}(w_j x + b_j)$ is affine on each side of $x = -b_j/w_j$. If $w_j = 0$ it is constant.

Step 2: count. The at most $m$ kink points cut $\R$ into at most $m + 1$ intervals. On each interval every unit is affine, hence so is their sum $f_\theta$. A sum of continuous functions is continuous.

Let $T(x) = 2\operatorname{ReLU}(x) - 4\operatorname{ReLU}\big(x - \tfrac12\big)$. On $[0, 1]$ this is the tent map: $T(x) = 2x$ on $[0, \frac12]$ and $T(x) = 2 - 2x$ on $[\frac12, 1]$, and $T$ maps $[0, 1]$ onto $[0, 1]$. The composition $T^{\circ L} = T \circ \dots \circ T$ ($L$ times) is a network with $L$ hidden layers of two ReLU units each: $2L$ hidden units.

Step 1: the claim. On $[0, 1]$, $T^{\circ L}$ has $2^L$ linear pieces, with slopes alternating $+2^L, -2^L, +2^L, \dots, -2^L$ from left to right.

Step 2: $L = 1$. $T$ has two pieces with slopes $+2, -2$.

Step 3: left half. Assume the claim for $g = T^{\circ(L-1)}$. On $[0, \frac12]$, $T^{\circ L}(x) = g(2x)$: the graph of $g$ squeezed into $[0, \frac12]$. It has the $2^{L-1}$ pieces of $g$, with slopes multiplied by $2$: alternating $+2^L, \dots, -2^L$.

Step 4: right half. On $[\frac12, 1]$, $T^{\circ L}(x) = g(2 - 2x)$: the graph of $g$ squeezed and mirrored. It has $2^{L-1}$ pieces with slopes multiplied by $-2$, met in reverse order, so they alternate again, starting with $(-2)(-2^{L-1}) = +2^L$.

Step 5: count. At $x = \frac12$ the slope changes from $-2^L$ to $+2^L$, so no pieces merge: $2^{L-1} + 2^{L-1} = 2^L$ pieces, alternating.

Step 6: compare. By , a one-hidden-layer network needs at least $2^L - 1$ hidden units to represent $T^{\circ L}$ exactly. The deep network uses $2L$. For $L = 20$: $40$ units against more than a million.

Each layer folds the input space onto itself, and the next layer acts on all folds at once. Results of this kind explain why depth helps; how to train deep networks well is the subject of the next chapter.

In code, a network is a list of layers. In PyTorch, as in the labs:

import torch.nn as nn

model = nn.Sequential(
    nn.Linear(2, 16), nn.ReLU(),     # W(1): 16 × 2,  b(1): 16
    nn.Linear(16, 16), nn.ReLU(),    # W(2): 16 × 16, b(2): 16
    nn.Linear(16, 1),                # output logit; the sigmoid goes into the loss
)
sum(p.numel() for p in model.parameters())   # 48 + 272 + 17 = 337

Strengths, limitations and connections

  • Strengths. Fixed size and cost per prediction, whatever $N$; universal approximation; the features are learned, which is decisive for raw inputs (images, sound, text); the same building blocks work for regression and classification.
  • Training is harder. The loss is not convex, results depend on the initialisation and on optimisation settings, and gradients can vanish or units can die.
  • Many parameters. Networks can overfit and need regularisation and validation; they usually need more data than the methods of the previous chapters.
  • Interpretability. Individual weights rarely have a meaning, unlike the coefficients of a linear model or the splits of a single tree.

Connections. One neuron is linear or logistic regression. A one-hidden-layer network is a linear model on learned features, where kernel methods use fixed ones. A ReLU network is piecewise linear, like a tree is piecewise constant, but its pieces are not aligned with the axes. Next, we compute gradients with backpropagation and train networks with many parameters.

Key takeaways

  • A neural network stacks layers $\ba^{(\ell)} = \sigma^{(\ell)}(\bW^{(\ell)}\ba^{(\ell-1)} + \bb^{(\ell)})$. It has a fixed number of parameters, $\sum_\ell n_\ell(n_{\ell-1} + 1)$, and learns its own features.
  • One neuron with a sigmoid is logistic regression; the output layer of any network is a linear or logistic model on the last hidden layer.
  • Without non-linear activations every network is affine, and no affine classifier solves XOR.
  • Sigmoid and tanh saturate ($\sigma' \leq \frac14$), which makes gradients vanish through many layers. ReLU does not saturate for $z > 0$ but units can die; leaky ReLU fixes that.
  • The output activation matches the task: identity, sigmoid or softmax. Softmax is shift invariant and reduces to the sigmoid for two classes.
  • One hidden layer can approximate any continuous function on a bounded set (for any continuous non-polynomial activation). The theorem is existential, says nothing about training or generalisation, and may need very many units; depth can be exponentially more economical.

Probabilistic view: output layers and likelihoods

Each pairing of output activation and loss in is maximum likelihood for a probability model whose parameters are produced by the network.

Let the training pairs be independent given the inputs. Then minimising the loss on the left is equivalent to maximising the likelihood of the model on the right:

  • squared error $\sum_i (y_i - f_\theta(\bx_i))^2$ $\iff$ $y \mid \bx \sim \mathcal N\big(f_\theta(\bx), s^2\big)$ with $s^2$ fixed;
  • binary cross-entropy $\iff$ $y \mid \bx \sim \operatorname{Bernoulli}\big(\sigma(z_\theta(\bx))\big)$;
  • cross-entropy $-\sum_i \log\operatorname{softmax}(\mathbf z_\theta(\bx_i))_{y_i}$ $\iff$ $y \mid \bx \sim \operatorname{Categorical}\big(\operatorname{softmax}(\mathbf z_\theta(\bx))\big)$.
Proof

Step 1: the log-likelihood is a sum. By independence, $$\log \prod_{i=1}^N p_\theta(y_i \mid \bx_i) = \sum_{i=1}^N \log p_\theta(y_i \mid \bx_i),$$ and maximising it is minimising $-\sum_i \log p_\theta(y_i \mid \bx_i)$.

Step 2: Gaussian. $$-\log p_\theta(y \mid \bx) = \frac{\big(y - f_\theta(\bx)\big)^2}{2s^2} + \underbrace{\tfrac12\log(2\pi s^2)}_{\text{does not depend on } \theta},$$ so the negative log-likelihood is the squared error up to a positive factor and a constant.

Step 3: Bernoulli. With $p = \sigma(z_\theta(\bx))$, $-\log p_\theta(y \mid \bx) = -y\log p - (1 - y)\log(1 - p)$, the binary cross-entropy.

Step 4: categorical. $-\log p_\theta(y \mid \bx) = -\log\operatorname{softmax}(\mathbf z_\theta(\bx))_y$, the cross-entropy.

So a network for classification is a model of $\P(y \mid \bx)$, exactly as logistic regression, with the linear predictor replaced by a learned non-linear one. The Gaussian case also suggests extensions: a network can output both a mean and a variance, and be trained by maximising the full Gaussian likelihood to predict its own uncertainty.
