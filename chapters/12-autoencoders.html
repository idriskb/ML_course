Autoencoders

PCA compresses data by projecting onto a few directions. An autoencoder compresses data with a neural network: an encoder maps each input to a short code, a decoder maps the code back, and both are trained so that the output reproduces the input. No labels are needed. We prove that a linear autoencoder learns exactly the PCA subspace, and then see what non-linear autoencoders add: curved representations, denoising, and anomaly detection.

Learning to reconstruct

In Chapter 5, PCA summarised each data point $\bx \in \R^p$ by $k$ numbers, the scores $\bz = U_k\T\bx$, and reconstructed it as $\hat\bx = U_k\bz$. Both maps are linear. An autoencoder keeps this structure, a map to $k$ numbers and a map back, and lets both be neural networks.

An autoencoder consists of an encoder $g_\phi : \R^p \to \R^k$ and a decoder $h_\psi : \R^k \to \R^p$, both neural networks with parameters $\phi$ and $\psi$. The code (or latent representation) of $\bx$ is $\bz = g_\phi(\bx)$ and its reconstruction is $\hat\bx = h_\psi(g_\phi(\bx))$. Given unlabelled data $\bx_1, \dots, \bx_n$, the parameters minimise the reconstruction error $$J(\phi, \psi) = \frac1n\sum_{i=1}^n \norm{\bx_i - h_\psi\big(g_\phi(\bx_i)\big)}^2 .$$

The input plays the role of the target, so this is supervised learning with $y = \bx$: the same networks, backpropagation and optimisers as in Chapter 11 apply unchanged. What makes the task non-trivial is the bottleneck. If $k \geq p$, the encoder and decoder can both be the identity and $J = 0$ without learning anything. With $k < p$ (an undercomplete autoencoder) the network is forced to keep, in $k$ numbers, whatever is most useful to rebuild the input: the main structure of the data.

For $8 \times 8$ images of digits ($p = 64$), an encoder $64 \to 32 \to 2$ and a decoder $2 \to 32 \to 64$ with tanh hidden layers and linear code and output layers. The code of each image is a point in the plane, which can be plotted like the first two PCA scores. By Chapter 10 the network has $32 \cdot 65 + 2 \cdot 33 + 32 \cdot 3 + 64 \cdot 33 = 4\,354$ parameters.

Linear autoencoders and PCA

Take the data centred, $\sum_i\bx_i = \mathbf 0$, with covariance $\Sigma = \frac1n\sum_i\bx_i\bx_i\T$ and eigen-decomposition $\Sigma = U\Lambda U\T$, $\lambda_1 \geq \dots \geq \lambda_p \geq 0$, as in Chapter 5. A linear autoencoder has no activations and no biases: an encoder matrix $E \in \R^{k \times p}$ and a decoder matrix $D \in \R^{p \times k}$, $$\bz = E\bx, \qquad \hat\bx = D\bz = DE\,\bx, \qquad J(E, D) = \frac1n\sum_{i=1}^n\norm{\bx_i - DE\,\bx_i}^2 .$$ Chapter 5 showed that projecting onto the first $k$ principal directions leaves the error $\lambda_{k+1} + \dots + \lambda_p$. We first prove that no other subspace does better.

Let $V \in \R^{p \times k}$ have orthonormal columns, spanning a subspace $S$. The orthogonal projection onto $S$ is $VV\T$, and $$\frac1n\sum_{i=1}^n\norm{\bx_i - VV\T\bx_i}^2 = \tr(\Sigma) - \tr\big(V\T\Sigma V\big) .$$

Proof

Step 1: one point. Expand and use $V\T V = I_k$: $$\norm{\bx - VV\T\bx}^2 = \norm{\bx}^2 - 2\,\bx\T VV\T\bx + \bx\T V\underbrace{V\T V}_{=\ I_k}V\T\bx = \norm{\bx}^2 - \norm{V\T\bx}^2 .$$

Step 2: average. $\frac1n\sum_i\norm{\bx_i}^2 = \tr(\Sigma)$ as in Chapter 5, and $$\frac1n\sum_i\norm{V\T\bx_i}^2 = \frac1n\sum_i\tr\big(V\T\bx_i\bx_i\T V\big) = \tr\big(V\T\Sigma V\big) .$$

For every $V \in \R^{p \times k}$ with orthonormal columns, $$\tr\big(V\T\Sigma V\big) \leq \lambda_1 + \dots + \lambda_k ,$$ with equality for $V = U_k$. Hence the smallest reconstruction error of any $k$-dimensional subspace is $\lambda_{k+1} + \dots + \lambda_p$, attained by the PCA subspace.

Proof

Step 1: expand in the eigenbasis. With $\Sigma = \sum_{j=1}^p\lambda_j\bu_j\bu_j\T$, $$\tr\big(V\T\Sigma V\big) = \sum_{j=1}^p\lambda_j\,\tr\big(V\T\bu_j\bu_j\T V\big) = \sum_{j=1}^p\lambda_j\,c_j, \qquad c_j = \norm{V\T\bu_j}^2 .$$

Step 2: the weights $c_j$ lie in $[0, 1]$. $VV\T$ is an orthogonal projection, so $c_j = \bu_j\T VV\T\bu_j = \norm{VV\T\bu_j}^2 \leq \norm{\bu_j}^2 = 1$.

Step 3: they add up to $k$. $U$ is orthogonal, so $$\sum_{j=1}^p c_j = \norm{V\T U}_F^2 = \tr\big(V\T UU\T V\big) = \tr\big(V\T V\big) = \tr(I_k) = k .$$

Step 4: compare with $\lambda_1 + \dots + \lambda_k$. $$\sum_{j=1}^p\lambda_jc_j - \sum_{j=1}^k\lambda_j = \sum_{j=1}^k\lambda_j\underbrace{(c_j - 1)}_{\leq\ 0} + \sum_{j=k+1}^p\lambda_j\underbrace{c_j}_{\geq\ 0} \leq \lambda_k\sum_{j=1}^k(c_j - 1) + \lambda_k\sum_{j=k+1}^p c_j ,$$ because $\lambda_j \geq \lambda_k$ in the first sum and $\lambda_j \leq \lambda_k$ in the second. The right-hand side is $$\lambda_k\Big(\underbrace{\sum_{j=1}^p c_j}_{=\ k} - k\Big) = 0 .$$

Step 5: equality and conclusion. For $V = U_k$, $c_j = 1$ for $j \leq k$ and $0$ otherwise, so equality holds. By , the error of $S$ is $\tr(\Sigma) - \tr(V\T\Sigma V) \geq \sum_{j=1}^p\lambda_j - \sum_{j=1}^k\lambda_j$.

For centred data and $k \leq p$, $$\min_{E,\,D}\ J(E, D) = \lambda_{k+1} + \dots + \lambda_p ,$$ the PCA reconstruction error. The minimum is attained by $E = U_k\T$, $D = U_k$ (PCA itself), and also by $E = AU_k\T$, $D = U_kA^{-1}$ for every invertible $A \in \R^{k \times k}$.

Proof

Step 1: the reconstructions lie in a $k$-dimensional subspace. Every $\hat\bx_i = D(E\bx_i)$ lies in the column space of $D$, which has dimension at most $k$. Choose a $k$-dimensional subspace $S$ containing it, with orthonormal basis $V$.

Step 2: the projection is the closest point. For each $i$, $VV\T\bx_i$ is the point of $S$ closest to $\bx_i$ (Chapter 2, least squares is a projection), and $\hat\bx_i \in S$, so $$\norm{\bx_i - \hat\bx_i}^2 \geq \norm{\bx_i - VV\T\bx_i}^2 .$$

Step 3: lower bound. Average over $i$ and apply and : $$J(E, D) \geq \tr(\Sigma) - \tr\big(V\T\Sigma V\big) \geq \lambda_{k+1} + \dots + \lambda_p .$$

Step 4: attained. With $E = U_k\T$, $D = U_k$, $DE = U_kU_k\T$ is the PCA reconstruction, whose error is $\lambda_{k+1} + \dots + \lambda_p$ (Chapter 5).

Step 5: not unique. For invertible $A$, $$\big(U_kA^{-1}\big)\big(AU_k\T\big) = U_k\underbrace{A^{-1}A}_{=\ I_k}U_k\T = U_kU_k\T ,$$ the same reconstructions, hence the same error.

So a linear autoencoder trained by gradient descent can at best match PCA, and in practice it does reach PCA's error. But it learns the principal subspace, not the principal directions: its code is $\bz = AU_k\T\bx$, an arbitrary invertible linear transformation of the PCA scores. The coordinates of the code need not be uncorrelated or ordered by variance, unlike PCA's. The equality of the two errors can be seen in with the linear autoencoder.

Non-linear autoencoders

With non-linear activations, the set of possible reconstructions $\{h_\psi(\bz) : \bz \in \R^k\}$ is no longer a subspace but a curved $k$-dimensional surface in $\R^p$ (a curve when $k = 1$). The encoder learns where on this surface to send each point, and the decoder learns the surface. When the data lie near a curved low-dimensional shape, a non-linear autoencoder can follow it, while PCA can only fit a flat subspace.

The extra flexibility has the usual price. The loss is not convex, the result depends on the initialisation, and a very flexible decoder can memorise the training set instead of capturing its structure. The code is also not unique: as for the linear case, any invertible transformation of the code can be absorbed by the decoder, so the individual coordinates of $\bz$ have no fixed meaning.

Training and choosing the code size

  • Loss. The squared error is standard. For inputs in $[0, 1]$, such as grey-level pixels, a sigmoid output with the binary cross-entropy summed over pixels is also common.
  • Architecture. Usually a mirror image: the decoder has the encoder's layer widths in reverse order. The code layer has no activation (or a mild one), so that codes can take any value.
  • Code size $k$. Plot the validation reconstruction error against $k$, as with the explained variance in Chapter 5, and choose the point after which it stops improving much. Smaller $k$ means more compression; for visualisation, $k = 2$ or $3$.
  • Overfitting. Monitor the reconstruction error on held-out data and use the tools of Chapter 11 (weight decay, early stopping).

Variants and uses

Denoising autoencoders

A denoising autoencoder is trained to reconstruct each clean input from a corrupted copy $\tilde\bx_i$ (for example $\tilde\bx_i = \bx_i + \boldsymbol\varepsilon_i$ with small Gaussian noise, or $\bx_i$ with a random subset of its entries set to zero, drawn afresh at every step): $$J(\phi, \psi) = \frac1n\sum_{i=1}^n\norm{\bx_i - h_\psi\big(g_\phi(\tilde\bx_i)\big)}^2 .$$

The identity no longer solves the problem, even without a bottleneck, because the input is not the target. To remove the noise the network must learn what typical data look like and pull corrupted inputs back towards them. The trained network can be used to clean noisy inputs, and its codes tend to be more robust features.

Anomaly detection

An autoencoder trained on normal data reconstructs normal inputs well and unusual inputs poorly, because its bottleneck only keeps the structure it has seen. The reconstruction error $r(\bx) = \norm{\bx - \hat\bx}^2$ is therefore an anomaly score: flag $\bx$ if $r(\bx)$ exceeds a threshold, for instance the 99th percentile of $r$ on validation data. Typical uses are fraud detection, monitoring of machines and quality control. PCA can be used in the same way, with its own reconstruction error.

Other uses

  • Dimensionality reduction and visualisation, as a non-linear alternative to PCA (and to kernel PCA, Chapter 9): plot the codes for $k = 2$.
  • Feature learning. Train the autoencoder on plenty of unlabelled data, then use the encoder as the first layers of a classifier trained on fewer labelled examples.
  • Compression. Store or transmit the code instead of the input.
  • Sparse autoencoders add a penalty such as $\mu\sum_i\norm{\bz_i}_1$ on the codes, so that each input uses few active code units; this allows codes larger than $p$ without learning the identity.

Strengths, limitations and connections

  • Strengths. Learn from unlabelled data; non-linear, so they can follow curved structure; scale to large data sets with mini-batch training; the encoder gives a reusable representation.
  • Limitations. Non-convex training with a result that depends on initialisation; codes that are not unique and whose coordinates have no fixed meaning (PCA's are ordered and uncorrelated); more hyperparameters than PCA; a risk of memorising the training data.
  • Not a generative model. Decoding an arbitrary code does not necessarily give a realistic input, because nothing controls where the codes of the data lie. The variational autoencoder (Extra) fixes this.

Connections. The linear autoencoder is PCA (), and the proof completes Chapter 5's statement that no other subspace does better. Kernel PCA (Chapter 9) and autoencoders are two non-linear extensions: one fixes the feature map through a kernel, the other learns it, which is the same contrast as between kernel methods and neural networks in Chapter 10. Each module of the course thus ends with an unsupervised method: PCA and k-means, kernel PCA, and autoencoders.

Key takeaways

  • An autoencoder is an encoder $g_\phi$ and a decoder $h_\psi$ trained without labels to minimise $\frac1n\sum_i\norm{\bx_i - h_\psi(g_\phi(\bx_i))}^2$; the bottleneck $k < p$ (or noise in the input) is what forces it to learn structure.
  • No $k$-dimensional subspace reconstructs better than the PCA subspace: the best error is $\lambda_{k+1} + \dots + \lambda_p$.
  • A linear autoencoder reaches exactly this error; it learns the principal subspace, with codes equal to the PCA scores up to an invertible linear map.
  • Non-linear autoencoders reconstruct along a learned curved surface, and can beat PCA by far on curved data, at the price of non-convex training and less interpretable codes.
  • Denoising autoencoders reconstruct clean inputs from corrupted ones; the reconstruction error is an anomaly score.

Probabilistic view: variational autoencoders

A variational autoencoder (VAE) turns the autoencoder into a generative model, just as probabilistic PCA (Chapter 5, Extra) turns PCA into one: codes have a prior distribution, so new data can be generated by sampling a code and decoding it.

A variational autoencoder has a prior $\bz \sim \mathcal N(\mathbf 0, I_k)$, a decoder model $p_\psi(\bx \mid \bz) = \mathcal N\big(h_\psi(\bz), s^2I_p\big)$, and an encoder that outputs a distribution over codes, $q_\phi(\bz \mid \bx) = \mathcal N\big(\boldsymbol\mu_\phi(\bx), \operatorname{diag}\boldsymbol\sigma^2_\phi(\bx)\big)$. It is trained by maximising, over $\phi$ and $\psi$, the sum over data points of the evidence lower bound $$\operatorname{ELBO}(\bx) = \E_{q_\phi(\bz \mid \bx)}\big[\log p_\psi(\bx \mid \bz)\big] - \operatorname{KL}\big(q_\phi(\bz \mid \bx)\,\big\|\,p(\bz)\big) .$$

For every $\bx$ and every distribution $q$ on codes, $\log p_\psi(\bx) \geq \operatorname{ELBO}(\bx)$, where $p_\psi(\bx) = \int p_\psi(\bx \mid \bz)\,p(\bz)\,d\bz$ is the likelihood of the generative model.

Proof

Step 1: insert $q$. $$\log p_\psi(\bx) = \log\int q(\bz)\,\frac{p_\psi(\bx \mid \bz)\,p(\bz)}{q(\bz)}\,d\bz = \log\E_q\Big[\frac{p_\psi(\bx \mid \bz)\,p(\bz)}{q(\bz)}\Big] .$$

Step 2: Jensen's inequality. $\log$ is concave, so $\log\E[Y] \geq \E[\log Y]$: $$\log p_\psi(\bx) \geq \E_q\big[\log p_\psi(\bx \mid \bz)\big] + \E_q\Big[\log\frac{p(\bz)}{q(\bz)}\Big] .$$

Step 3: recognise the KL divergence. $\E_q[\log(p(\bz)/q(\bz))] = -\operatorname{KL}(q\,\|\,p)$.

The first term of the ELBO is a reconstruction term: with the Gaussian decoder it is, up to constants, $-\frac{1}{2s^2}\E_q\norm{\bx - h_\psi(\bz)}^2$, the autoencoder loss evaluated at codes drawn around $\boldsymbol\mu_\phi(\bx)$. The second term pulls each code distribution towards the prior, so that the codes of the data fill the region where the prior samples, and decoding a random $\bz \sim \mathcal N(\mathbf 0, I)$ gives a plausible new input. In practice the expectation is estimated with one sample $\bz = \boldsymbol\mu_\phi(\bx) + \boldsymbol\sigma_\phi(\bx) \odot \boldsymbol\varepsilon$, $\boldsymbol\varepsilon \sim \mathcal N(\mathbf 0, I)$, which keeps $\bz$ a differentiable function of $\phi$ so that backpropagation applies (the reparametrisation trick), and the KL term between two Gaussians has the closed form $\frac12\sum_{j}\big(\mu_j^2 + \sigma_j^2 - 1 - \log\sigma_j^2\big)$.

Show that for $k = 1$, $\operatorname{KL}\big(\mathcal N(\mu, \sigma^2)\,\|\,\mathcal N(0, 1)\big) = \frac12(\mu^2 + \sigma^2 - 1 - \log\sigma^2)$, and that it is zero only for $\mu = 0$, $\sigma = 1$. What happens to the codes if this term is given a very large weight?
