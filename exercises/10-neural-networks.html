Exercises: neural networks

Practice for Chapter 10. A layer computes $\mathbf z^{(\ell)} = \bW^{(\ell)}\ba^{(\ell-1)} + \bb^{(\ell)}$ and $\ba^{(\ell)} = \sigma^{(\ell)}(\mathbf z^{(\ell)})$, with $\ba^{(0)} = \bx$. Training (backpropagation) is the subject of the next set. The questions go from conceptual, to hand computations, to harder questions that link several ideas. Every exercise is followed by a collapsed solution: try the question first, then reveal the solution one step at a time.

What you will practise

  • Computing the forward pass of a small network by hand.
  • Counting the parameters of a network and comparing with other models.
  • Choosing the output layer for regression, binary and multi-class tasks; computing softmax and cross-entropy.
  • Explaining why activations must be non-linear and how sigmoid, tanh and ReLU differ.
  • Building piecewise linear functions with ReLU units, and explaining what universal approximation and depth give.

Core conceptual questions

Linear models, k-NN, trees and kernel methods were all seen before neural networks. Explain:

  1. what a linear model cannot do, and how adding fixed features (polynomials, kernels) addresses it;
  2. what a kernel method must store to make a prediction, and how its cost grows with the number $N$ of training points;
  3. what a neural network learns that a kernel method fixes in advance.
Solution

Step 1: (a) linear models. A linear model $\hat f(\bx) = \bw\T\bx + b$ can only represent planes, and as a classifier it can only draw a straight boundary. It cannot fit curvature, interactions, or the XOR pattern. Fixed features $\phi(\bx)$ (polynomials, or a kernel) fix this: the model is linear in $\phi(\bx)$ but non-linear in $\bx$. But the features are chosen before seeing the data, and polynomial features explode in number with $p$.

Step 2: (b) kernel methods. A kernel prediction is $$\hat f(\bx) = \sum_{i=1}^N \alpha_i\,k(\bx_i, \bx),$$ so all $N$ training inputs must be kept, and each prediction costs $N$ kernel evaluations. Fitting needs the $N \times N$ matrix $K$ ($N^2$ entries) and a solve costing about $N^3$. Doubling the data multiplies memory by 4 and fitting time by 8.

Step 3: (c) learned features. In a network, the hidden layers are the features: $\ba^{(L-1)}(\bx)$ plays the role of $\phi(\bx)$, and the output layer is a linear (or logistic) model on top. The weights of the hidden layers are fitted to the data, so the network learns which features to use, instead of using a feature map fixed in advance by the choice of kernel.

Step 4: conclude. The number of parameters is set by the architecture, not by $N$. Predictions cost the same whatever the size of the training set, which makes networks practical for very large datasets.

A neuron computes $a = \sigma(\bw\T\bx + b)$.

  1. Which model from earlier chapters is a single neuron with the identity activation, trained with squared error? And with the sigmoid activation, trained with cross-entropy?
  2. Describe the set of inputs $\{\bx : \bw\T\bx + b > 0\}$ geometrically.
  3. Explain why no single neuron with a monotone activation and a threshold can classify the XOR points $(0,0), (1,1) \mapsto 0$ and $(1,0), (0,1) \mapsto 1$.
Solution

Step 1: (a) familiar models. With $\sigma(z) = z$ the neuron is $a = \bw\T\bx + b$: linear regression (Chapter 2). With the sigmoid, $a = \sigma(\bw\T\bx + b) \in (0, 1)$ is a probability score: logistic regression (Chapter 4).

Step 2: (b) a half-space. The equation $\bw\T\bx + b = 0$ is a hyperplane (a line in $\R^2$) orthogonal to $\bw$. The set where $\bw\T\bx + b > 0$ is the half-space on the side $\bw$ points to.

Step 3: (c) XOR. With a monotone activation, thresholding $a$ is the same as thresholding $z = \bw\T\bx + b$, so the neuron predicts class 1 exactly on a half-space. Suppose it classified XOR correctly. Then $$z(1,0) > 0, \quad z(0,1) > 0 \quad\Longrightarrow\quad z(1,0) + z(0,1) = w_1 + w_2 + 2b > 0,$$ $$z(0,0) \le 0, \quad z(1,1) \le 0 \quad\Longrightarrow\quad z(0,0) + z(1,1) = w_1 + w_2 + 2b \le 0 .$$ The two sums are the same number, a contradiction.

Step 4: conclude. One neuron draws one straight boundary. Non-linear boundaries need several neurons combined through a hidden layer.

For each lab dataset, give the number of output units, the output activation, the loss, and what the output means: (a) house prices (predict the price); (b) breast cancer (malignant or benign); (c) digits (which of the ten digits). Then say which PyTorch loss you would use in each case, and why the network itself often ends with no activation.

Solution

Step 1: (a) regression. One output unit, identity activation, squared error. The output is the predicted price $\hat y \in \R$; no activation is needed because a price can be any real number.

Step 2: (b) binary classification. One output unit with the sigmoid, $\hat p = \sigma(z) \in (0, 1)$, the predicted probability of "malignant", trained with binary cross-entropy $$-\big[y\log\hat p + (1 - y)\log(1 - \hat p)\big] .$$ The class is obtained by thresholding $\hat p$ (at $\frac12$ by default, lower if missing a malignant tumour is costly).

Step 3: (c) $K = 10$ classes. Ten output units with the softmax, giving ten probabilities that sum to 1, trained with cross-entropy $-\log\hat p_y$. The predicted digit is the one with the largest probability.

Step 4: in PyTorch. (a) nn.Linear(h, 1) with nn.MSELoss(); (b) nn.Linear(h, 1) with nn.BCEWithLogitsLoss(); (c) nn.Linear(h, 10) with nn.CrossEntropyLoss(). In (b) and (c) the network outputs logits $z$, and the sigmoid or softmax is applied inside the loss. Combining them is numerically safer: it avoids computing $\log$ of a probability that has been rounded to 0. To get probabilities at prediction time, apply torch.sigmoid or torch.softmax to the outputs.

  1. A student builds a network with five hidden layers of width 100 but forgets the activation functions (every layer is $\mathbf z = \bW\ba + \bb$). What function class does the network represent?
  2. Could the student's network ever fit the two moons better than logistic regression?
  3. A second student uses the activation $\sigma(z) = z^2$ in one hidden layer. What functions can this network represent, however many hidden units it has?
Solution

Step 1: (a) a composition of affine maps is affine. With two layers, $$\bW^{(2)}\big(\bW^{(1)}\bx + \bb^{(1)}\big) + \bb^{(2)} = \underbrace{\bW^{(2)}\bW^{(1)}}_{\tilde\bW}\bx + \underbrace{\bW^{(2)}\bb^{(1)} + \bb^{(2)}}_{\tilde\bb},$$ and by induction any number of layers gives $f(\bx) = \tilde\bW\bx + \tilde\bb$. The five layers and their tens of thousands of parameters represent only affine maps.

Step 2: (b) no better than logistic regression. If the output is passed through a sigmoid, the model is $\sigma(\tilde\bw\T\bx + \tilde b)$: exactly logistic regression, with a straight boundary. It cannot follow the curved moons. The extra layers only make training harder.

Step 3: (c) a polynomial activation. Each hidden unit computes $(\bw_j\T\bx + b_j)^2$, a polynomial of degree 2 in $\bx$, and the output is a weighted sum of them: $$f(\bx) = c + \sum_{j=1}^m v_j\,(\bw_j\T\bx + b_j)^2 ,$$ a polynomial of degree at most 2, whatever $m$ is. It can never approximate, say, $x^3$ or a step function well. This is why the universal approximation theorem requires an activation that is not a polynomial; ReLU, sigmoid and tanh all qualify.

Intermediate exercises

A network has two inputs, two ReLU hidden units and one sigmoid output: $$\bW^{(1)} = \begin{pmatrix} 1 & -1 \\ 2 & 1 \end{pmatrix}, \quad \bb^{(1)} = \begin{pmatrix} 0 \\ -1 \end{pmatrix}, \quad \bW^{(2)} = \begin{pmatrix} 2 & -1 \end{pmatrix}, \quad b^{(2)} = -0.5 .$$

  1. Compute $\mathbf z^{(1)}$, $\ba^{(1)}$, the output logit $z^{(2)}$ and the probability $\hat p = \sigma(z^{(2)})$ at $\bx = (1, 2)$.
  2. Do the same at $\bx = (2, 0)$ and at $\bx = (-1, 1)$.
  3. Give the predicted class at the three points (threshold $\frac12$). Which hidden units are inactive at each point, and what does an inactive unit contribute?
Solution

Step 1: (a) $\bx = (1, 2)$. $$\mathbf z^{(1)} = \begin{pmatrix} 1 - 2 + 0 \\ 2 + 2 - 1 \end{pmatrix} = \begin{pmatrix} -1 \\ 3 \end{pmatrix}, \qquad \ba^{(1)} = \operatorname{ReLU}(\mathbf z^{(1)}) = \begin{pmatrix} 0 \\ 3 \end{pmatrix},$$ $$z^{(2)} = 2(0) - 1(3) - 0.5 = -3.5, \qquad \hat p = \sigma(-3.5) = \frac{1}{1 + e^{3.5}} \approx 0.029 .$$

Step 2: (b) $\bx = (2, 0)$. $\mathbf z^{(1)} = (2, 3)$, both units active, so $\ba^{(1)} = (2, 3)$ and $$z^{(2)} = 4 - 3 - 0.5 = 0.5, \qquad \hat p = \sigma(0.5) \approx 0.622 .$$

Step 3: (b) $\bx = (-1, 1)$. $\mathbf z^{(1)} = (-2, -2)$, so $\ba^{(1)} = (0, 0)$ and $$z^{(2)} = b^{(2)} = -0.5, \qquad \hat p = \sigma(-0.5) \approx 0.378 .$$

Step 4: (c) classes and inactive units. The predictions are class 0, class 1 and class 0. At $(1, 2)$ unit 1 is inactive; at $(2, 0)$ both are active; at $(-1, 1)$ both are inactive and the output is just the bias. An inactive ReLU unit outputs exactly 0, so it contributes nothing; the network acts as a different linear model in each region of input space, depending on which units are active.

Solution

Step 1: (a) the digits network. Each layer has a weight matrix $n_\ell \times n_{\ell-1}$ and $n_\ell$ biases: $$32(64 + 1) + 16(32 + 1) + 10(16 + 1) = 2080 + 528 + 170 = 2778 .$$

A three-class network outputs the logits $\mathbf z = (2, 1, -1)$. Use natural logarithms.

  1. Compute $\operatorname{softmax}(\mathbf z)$.
  2. Compute the cross-entropy loss $-\log\hat p_y$ if the true class is $y = 1$, and if it is $y = 3$.
  3. Subtract the largest logit from every logit and recompute the softmax. Why do implementations do this?
  4. What is the loss of a network that always outputs equal logits? And how is two-class softmax with logits $(2, 1)$ related to the sigmoid?
Solution

Step 1: (a) exponentiate and normalise. $$e^2 \approx 7.389, \qquad e^1 \approx 2.718, \qquad e^{-1} \approx 0.368, \qquad \text{sum} \approx 10.475,$$ $$\operatorname{softmax}(\mathbf z) \approx (0.705,\ 0.259,\ 0.035) .$$ The entries are positive and sum to 1.

Step 2: (b) cross-entropy. $$y = 1:\ -\log 0.705 \approx 0.349, \qquad y = 3:\ -\log 0.035 \approx 3.349 .$$ The loss is small when the true class gets a high probability and large when the network is confidently wrong.

Step 3: (c) shift the logits. $\mathbf z - 2 = (0, -1, -3)$, with exponentials $1, 0.368, 0.050$ and sum $1.418$: again $(0.705, 0.259, 0.035)$, because the factor $e^{-2}$ cancels between numerator and denominator. Implementations subtract the maximum so that every exponent is $\le 0$: then $e^{z_k}$ never overflows, even for logits like $1000$.

Step 4: (d) two reference points. Equal logits give $\hat p_k = \frac13$ for every class, so the loss is $\log 3 \approx 1.099$ whatever the true class: a network that has learnt nothing starts near this value. With two classes, dividing by $e^{z_1}$ gives $$\frac{e^{2}}{e^{2} + e^{1}} = \frac{1}{1 + e^{-(2 - 1)}} = \sigma(1) \approx 0.731,$$ the sigmoid of the difference of the logits.

  1. Using $\sigma'(z) = \sigma(z)(1 - \sigma(z))$, compute $\sigma'(0)$, $\sigma'(2)$ and $\sigma'(5)$.
  2. Using $\tanh'(z) = 1 - \tanh^2 z$, compute $\tanh'(0)$ and $\tanh'(1)$ (use $\tanh 1 \approx 0.762$).
  3. A chain of $L$ sigmoid neurons has all weights $w_\ell = 1$, and biases chosen so that every pre-activation equals 0. Compute $da_L/dx = \prod_\ell \sigma'(z_\ell)\,w_\ell$ for $L = 5$ and $L = 10$.
  4. What is the same product for a chain of ReLU units with weights 1 and positive pre-activations? Why does this matter for deep networks?
Solution

Step 1: (a) sigmoid. $\sigma(0) = 0.5$, $\sigma(2) \approx 0.881$, $\sigma(5) \approx 0.993$, so $$\sigma'(0) = 0.25, \qquad \sigma'(2) \approx 0.881 \times 0.119 \approx 0.105, \qquad \sigma'(5) \approx 0.993 \times 0.007 \approx 0.0066 .$$ The derivative is at most $\frac14$ and almost 0 once the unit saturates.

Step 2: (b) tanh. $\tanh'(0) = 1$ and $\tanh'(1) \approx 1 - 0.762^2 \approx 0.420$. Tanh has a larger maximum slope than the sigmoid, but it also saturates.

Step 3: (c) a sigmoid chain. Each factor is $\sigma'(0)\cdot 1 = \frac14$: $$L = 5:\ \Big(\frac14\Big)^5 \approx 9.8 \times 10^{-4}, \qquad L = 10:\ \Big(\frac14\Big)^{10} \approx 9.5 \times 10^{-7} .$$ And this is the best case: any saturated unit makes the product even smaller.

Step 4: (d) a ReLU chain. For a positive pre-activation $\operatorname{ReLU}'(z) = 1$, so the product is $1^L = 1$ for any depth. The derivative with respect to early layers does not shrink just because the network is deep. This is a main reason why ReLU replaced the sigmoid in hidden layers: training (next set) uses these derivatives, and with sigmoids the early layers of a deep network barely learn.

Consider $f(x) = \operatorname{ReLU}(x) - 2\operatorname{ReLU}(x - 1) + 2\operatorname{ReLU}(x - 3)$.

  1. Write $f$ as a one-hidden-layer network: give each hidden unit's weight and bias, and the output weights.
  2. Find the breakpoints and the slope of $f$ on each piece.
  3. Compute $f(-1)$, $f(0.5)$, $f(2)$, $f(4)$ and $f(5)$, and sketch $f$ on $[-1, 5]$.
  4. How many linear pieces can a one-hidden-layer ReLU network with one input and 3 hidden units have at most? Does $f$ reach that number?
Solution

Step 1: (a) the network. Three hidden units with weights $w_j = 1$ and biases $b_1 = 0$, $b_2 = -1$, $b_3 = -3$; output weights $v = (1, -2, 2)$ and output bias $c = 0$: $$f(x) = \sum_{j=1}^3 v_j\operatorname{ReLU}(w_jx + b_j) .$$

Step 2: (b) slopes. Unit $j$ switches on at $x = -b_j/w_j$, so the breakpoints are $0, 1, 3$. Each time a unit switches on, the slope changes by its output weight:

IntervalActive unitsSlope
$x \lt 0$none$0$
$0 \lt x \lt 1$1$1$
$1 \lt x \lt 3$1, 2$1 - 2 = -1$
$x > 3$1, 2, 3$-1 + 2 = 1$

Step 3: (c) values. $$f(-1) = 0, \quad f(0.5) = 0.5, \quad f(2) = 2 - 2 = 0, \quad f(4) = 4 - 6 + 2 = 0, \quad f(5) = 5 - 8 + 4 = 1 .$$ With $f(1) = 1$ and $f(3) = -1$, the graph is flat at 0, rises to 1 at $x = 1$, falls to $-1$ at $x = 3$, then rises again with slope 1: a zig-zag made of straight pieces.

Step 4: (d) counting pieces. $m$ hidden units give at most $m$ breakpoints, so at most $m + 1 = 4$ pieces. $f$ has exactly 4: each unit adds a breakpoint at a different place, and each changes the slope.

We approximate $f(x) = x^2$ on $[0, 2]$ by the broken line that joins the points $(x_k, x_k^2)$ for equally spaced knots $x_k$ with spacing $h$. For such a broken line, $\max|f - g| \le \frac{h^2}{8}\max|f''|$.

  1. Show that $g(x) = \operatorname{ReLU}(x) + 2\operatorname{ReLU}(x - 1)$ is the broken line with knots $0, 1, 2$ ($h = 1$). What is its largest error, and where?
  2. Find the output weights of the broken line with knots $0, 0.5, 1, 1.5, 2$, written as $\sum_j v_j\operatorname{ReLU}(x - x_j)$. What is its largest error?
  3. How many hidden units are needed for an error of at most $0.001$?
Solution

Step 1: (a) $h = 1$. $g(0) = 0$, $g(1) = 1$, $g(2) = 2 + 2 = 4$, matching $x^2$ at the knots, and $g$ is linear in between with slopes 1 and 3. The error bound is $$\frac{h^2}{8}\max|f''| = \frac{1}{8}\cdot 2 = 0.25 .$$ It is attained at the midpoints: $g(0.5) - 0.25 = 0.25$ and $g(1.5) - 2.25 = 2.5 - 2.25 = 0.25$.

Step 2: (b) $h = 0.5$. The chord slopes on the four pieces are $$\frac{0.25 - 0}{0.5} = 0.5, \quad \frac{1 - 0.25}{0.5} = 1.5, \quad \frac{2.25 - 1}{0.5} = 2.5, \quad \frac{4 - 2.25}{0.5} = 3.5 .$$ The first unit sets the first slope, and each later unit adds the change of slope: $$g(x) = 0.5\operatorname{ReLU}(x) + \operatorname{ReLU}(x - 0.5) + \operatorname{ReLU}(x - 1) + \operatorname{ReLU}(x - 1.5) .$$ The error bound is $\frac{0.25}{8}\cdot 2 = 0.0625$: halving $h$ divides the error by 4.

Step 3: (c) error $0.001$. We need $$\frac{h^2}{4} \le 0.001 \quad\Longleftrightarrow\quad h \le \sqrt{0.004} \approx 0.063 .$$ $[0, 2]$ then needs $2/h \ge 31.6$ pieces, so 32 pieces ($h = 1/16$, error $\approx 0.00098$), and one hidden unit per piece: 32 units.

Step 4: conclude. This is the construction behind universal approximation in one dimension: more units give finer broken lines and smaller errors.

  1. Classify the points $(0.3, 0.3)$, $(0.6, 0.6)$, $(2, -3)$ and $(-2, 0.5)$.
  2. Write $f$ as a linear function in each of the four quadrants, and find the decision boundary $f = 0$ in each.

Solution

Let $T(x) = 2\operatorname{ReLU}(x) - 4\operatorname{ReLU}(x - \frac12)$, the tent map on $[0, 1]$.

  1. Compute $T(0.3)$, $T(T(0.3))$ and $T(T(T(0.3)))$.
  2. The composition $T^{\circ L}$ has $2^L$ linear pieces on $[0, 1]$ (stated in Chapter 10). How many hidden units does the deep network $T^{\circ 3}$ use, and how many pieces does it have?
  3. How many hidden units would a network with one hidden layer need to produce the same function?
  4. Repeat (b) and (c) for $L = 10$. What does this say about depth?
Solution

Step 1: (a) iterate. On $[0, \frac12]$, $T(x) = 2x$; on $[\frac12, 1]$, $T(x) = 2 - 2x$: $$T(0.3) = 0.6, \qquad T(0.6) = 2 - 1.2 = 0.8, \qquad T(0.8) = 2 - 1.6 = 0.4 .$$

Step 2: (b) the deep network. Each copy of $T$ is one hidden layer with 2 ReLU units, so $T^{\circ 3}$ has 3 hidden layers and $2 \times 3 = 6$ hidden units, and $2^3 = 8$ linear pieces.

Step 3: (c) one hidden layer. A one-hidden-layer ReLU network with $m$ units has at most $m + 1$ pieces. To get 8 pieces we need $$m + 1 \ge 8 \quad\Longrightarrow\quad m \ge 7 .$$

Step 4: (d) $L = 10$. The deep network uses $2 \times 10 = 20$ units for $2^{10} = 1024$ pieces. One hidden layer needs at least $1023$ units. The deep network's count grows linearly in $L$, the shallow one's exponentially: composing layers multiplies the number of pieces, while adding units side by side only adds to it. Some functions are far cheaper to build with depth.

The universal approximation theorem says that a one-hidden-layer network with a continuous, non-polynomial activation can approximate any continuous function on a closed and bounded set to any accuracy.

  1. A classmate concludes: "So one hidden layer is all we ever need, and a large enough network trained on our data will find the true function." Give three separate reasons why this does not follow.
  2. Why is the theorem still useful?
Solution

Step 1: (a) size. The theorem says that some number $m$ of units suffices, not that it is small. In , the error falls like $1/m^2$ in one dimension; in $p$ dimensions a grid of knots needs about $m^p$ units, which is hopeless for $p = 64$. And shows functions where one hidden layer needs exponentially more units than a deep network.

Step 2: (a) finding the parameters. The theorem says good parameters exist. It says nothing about whether training will find them: the loss of a network is not convex, and gradient methods can stop at poor points.

Step 3: (a) finite data. The theorem is about approximating a known function $f$. In practice we only see $N$ noisy samples. A network large enough to approximate anything can also fit the noise exactly, so a small training error does not imply a small test error. Generalisation needs validation and regularisation, as for every flexible model.

Step 4: (b) why it is still useful. It rules out a fundamental limitation: unlike a linear model, or a network with a polynomial activation (), a network is never stuck with too small a function class. If it fails, the cause is size, training or data, not the architecture's expressive power.
